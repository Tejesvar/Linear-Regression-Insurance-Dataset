# Insurance Charges Prediction using Linear Regression

## 🧠 Overview
This project builds a Linear Regression model to predict medical insurance charges based on factors like age, BMI, smoking status, and number of children.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Model Summary
- Used Linear Regression to model insurance charges
- Explored relationships between features and target variable
- Visualized correlations and regression line

## 📁 Files
- `Linear_Regression_with_insurance_data_set.ipynb`: Main notebook with data analysis and model training
- `README.md`: Project summary and instructions

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas matplotlib seaborn scikit-learn`
3. Open the notebook in Jupyter
4. Run cells sequentially to view analysis and predictions

## 📌 Use Case
Useful for insurance companies, data analysts, and healthcare researchers to estimate costs and understand key influencing factors.
